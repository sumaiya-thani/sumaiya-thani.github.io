Digital Commerce & Automation

API integrations and workflow automation that connect e-commerce platforms to the systems behind them.

Overview

Work on how e-commerce platforms connect to a business's internal operations. Salla and Zid handle the storefront; the value comes from getting their data into the systems that run everything else.

Problem and objectives

Manual data workflows between platforms and operations systems create inefficiency and errors.

Objectives: understand the existing workflows, replace manual steps with automated flows, and keep backend and business systems accurate.

My role and contributions

  • Analyzed business workflows across Salla and Zid and turned the inefficiencies I found into API-based technical solutions.
  • Designed and implemented API integrations between the e-commerce platforms and internal operations systems, replacing manual data workflows with automated flows.
  • Partnered with operational stakeholders to gather requirements and support ERP alignment, improving accuracy between backend and business systems.
  • Identified and resolved 12+ bugs across the integrated workflows, improving reliability and reducing operational errors.

Architecture and tools

An API layer sits between the platforms and the back office, moving data both ways.
